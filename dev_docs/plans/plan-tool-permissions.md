## Работы

- [ ] Удаление в проектах и в `workspace/` профиля переносит файл в корзину
      внутри данных приложения, а не в системную корзину; очистка корзины по
      сроку.
- [ ] «Откатить изменения этого ответа»: снимок файлов проекта и памяти
      перед первой записью в ходе ответа, откат из шагов ответа.
- [ ] Пересмотреть значения по умолчанию с учётом отката (например,
      `write: 'allow'` в пресете «Чтение и запись»).

## Критерии готовности

- `pnpm validate:all` без ошибок и предупреждений.
- Удалённое ассистентом восстанавливается из корзины приложения; откат ответа
  возвращает файлы и память к состоянию до него.
