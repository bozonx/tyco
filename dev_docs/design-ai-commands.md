# Дизайн: ИИ-команды

Статус: этап 1 реализован
Дата: 2026-10-31

---

## 1. Что это

ИИ-команда — обычная команда библиотеки (`commands`), которую исполняет инструмент
`core.aiTask`. Это LLM-агент: он выполняет промпт команды над текстом и может
запускать другие команды как свои инструменты. По сути это «скилл», описанный
текстом.

Отдельной библиотеки заданий, отдельного меню, режима активации `aiTasks` и его
хоткея больше нет. ИИ-команда получает всё, что есть у команд:

- страницы лаунчера (быстрые команды) и их хоткеи;
- слоты меню основных действий (`type: "command"`);
- голосовой вызов (`isVoiceEnabled`, `phrases`);
- внешний вызов через `tyco-ctl` и D-Bus (`isAvailableExternally`);
- чат: когда команды станут инструментами чата, ИИ-команды будут доступны там
  так же, как любые другие.

## 2. Разграничение

| Сущность                  | Что делает                                     | Сайд-эффекты                           |
| :------------------------ | :--------------------------------------------- | :------------------------------------- |
| Трансформации и стили     | Правило переписывает текст, `f(text) -> text`  | Нет                                    |
| Команда скрипта/вебхука/… | Детерминированное действие с настройками       | Фиксированные, заданы кодом/настройкой |
| ИИ-команда                | Агент выполняет промпт, может вызывать команды | Только через разрешённые команды       |

Правило переписывает текст, а команда выполняет действие. ИИ-команда без
разрешённых команд по поведению близка к трансформации. Трансформации и стили
остаются отдельными быстрыми меню с предпросмотром и diff.

## 3. Конфигурация

`toolConfig` команды с `toolId: "core.aiTask"` (`AiCommandToolConfig`,
`packages/shared/src/user-config/commands-config.ts`):

```ts
interface AiCommandToolConfig {
  prompt: string
  /** Команды, которые агент может запускать; никогда не сама команда */
  allowedCommandIds: string[]
  /** 1–50, по умолчанию 5; каждый вызов команды — шаг */
  maxSteps: number
}
```

Модель общая для всех ИИ-команд: `llm.tasks.aiTask.modelId`, она выбирается на
вкладке «Команды». Что делать с ответом, решает `outputAction` команды, как у
любой команды (`insertIntoWindow`, `showMenu`, `copyToClipboard`, `none`). При
`none` тост показывает начало ответа.

## 4. Исполнение

- `lib/ai-commands/ai-command-runner.ts` — цикл агента. Системный промпт состоит
  из `APP_CONFIG.aiInstructions.aiTask` и промпта команды. Разрешённые команды
  передаются модели как инструменты, все шаги выполняет один `stream` с
  `maxSteps`. Ответ — текст после последнего вызова инструмента, очищенный
  `cleanLlmOutput`.
- `lib/ai-commands/ai-command-tool.ts` — инструмент `core.aiTask`. Вложенные
  команды запускаются через `runCommand`: в сторе `tools` это `createToolInvoker`
  с `output: 'return'`. Агент сам заполняет вход команды по её схеме, так что
  структурированные инструменты не требуют отдельного LLM-разбора.
- Прогресс: на каждый вызов агент сообщает имя команды через
  `ToolCall.onProgress`, лаунчер показывает «Имя: выполняю „шаг“…».
- Отмена: сигнал запуска отменяет и вложенные команды.

### Защита от рекурсии

Команда никогда не предлагается агенту самой себе. Кроме того, у каждого
вложенного запуска есть цепочка вызвавших ИИ-команд: она хранится в `WeakMap`
по `AbortSignal`, который получает вложенный запуск. Команды из цепочки
исключаются, поэтому `A → B → A` невозможна. Отключённые, удалённые и
недоступные сейчас команды тоже не предлагаются.

### Подтверждения

Запросов подтверждения нет: пользователь сам выбирает, какие команды разрешены
ИИ-команде, и это выбор служит согласием. Политики `ask`/`deny` для отдельных
вызовов пока не нужны.

## 5. Лаунчер

- Поиск (Space): Enter запускает выделенную команду. Ctrl+Enter, а также Enter,
  когда ничего не найдено, запускают введённый текст как разовый запрос к ИИ
  (`adHocAiCommand`, вывод через меню результата).
- Ctrl+S сохраняет введённый текст как ИИ-команду (`savePromptAsCommand`). На
  странице с раскладкой команда занимает первую свободную клавишу. Страница без
  раскладки и так показывает все команды. Повторно тот же промпт не сохраняется.
- Без выделения лаунчер просит текст, как для любой команды, которая его
  принимает.
